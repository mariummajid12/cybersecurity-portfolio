# 🛠️ Setup & Configuration Guide

This guide will help you get the Threat Intelligence pipeline running locally. This project is designed to interface with a **MISP (Malware Information Sharing Platform)** instance.

## 1. Prerequisites
- **Python 3.8+**
- **pip** (Python package manager)
- Access to a **MISP Instance** (Local Docker or Remote)

## 2. Installation
Clone the repository and install the required dependencies:

```bash
git clone [https://github.com/mariummajid12/threat-intelligence.git](https://github.com/mariummajid12/threat-intelligence.git)
cd threat-intelligence
pip install -r requirements.txt
